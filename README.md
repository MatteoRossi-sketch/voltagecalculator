# voltagecalculator
The calculator is a single, self-contained HTML file whose complete source code is provided
in Section A.5 (saving the listing as an .html file allows it to be opened directly in any web
browser). It implements the model of Chapter 4 for a coplanar interdigitated pad over a layered
stack, with the two-level interface of Eqs. 4.17 and 4.18: contact patches at the contact gap gc
covering a fraction φ of the free area, and the remainder at the roughness gap gr. The field is
solved with an edge-singular Chebyshev expansion of ten terms, summed over odd harmonics;
the pressure follows from virtual work, and the holding voltage is obtained in closed form. It is
a calculation of the model of Chapter 4 and adds no physics to it.
